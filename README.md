# Site professionnel de Gedeon Syka

Site vitrine personnel genere a partir du CV de Gedeon Syka.

## Fichier

- `index.html` : site complet avec HTML, CSS et JavaScript integres.

## Utilisation locale

1. Telechargez `index.html`.
2. Ouvrez-le dans un navigateur pour previsualiser le site.
3. Remplacez les liens `#` de Facebook et LinkedIn par les URL publiques de vos profils.

## Publication sur GitHub Pages

1. Ouvrez **Settings -> Pages** du depot.
2. Choisissez la branche et le dossier `/root`, puis enregistrez.
3. Ouvrez l'URL GitHub Pages affichee par GitHub.

Le site est responsive et ne depend d'aucune bibliotheque externe.
